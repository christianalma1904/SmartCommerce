# SmartCommerce

Sistema de Gestión de E-commerce para pequeñas empresas.

## Objetivo
Diseñar una plataforma web para gestionar productos,
inventario, clientes, pedidos y ventas.

## Módulos
1. Autenticación y usuarios
2. Productos
3. Categorías
4. Inventario
5. Clientes
6. Carrito de compras
7. Pedidos
8. Pagos simulados
9. Dashboard de ventas

## Tecnologías propuestas
- React + TypeScript
- Python + Django REST Framework
- PostgreSQL
- Git y GitHub

## Estado
Etapa 1: Planeación del software.

## Alcance
El sistema permitirá administrar una tienda pequeña.
Los pagos reales y las recomendaciones con IA
quedan fuera de la primera versión.
