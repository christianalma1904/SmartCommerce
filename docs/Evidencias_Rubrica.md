# Evidencias de evaluación — Unidad 1

La rúbrica compartida contiene tres criterios con **4 puntos cada uno**, para un máximo de **12 puntos**. Los materiales buscan cumplir el nivel **Alcanzado**; esto **no garantiza la calificación**.

| Criterio | Qué solicita el descriptor Alcanzado | Evidencia concreta |
|---|---|---|
| Relaciones con la disciplina | combinar ejemplos, hechos o teorías de más de un campo para concluir | [Planificación, sección 3](Planificacion_Unidad1.md): integra software, datos, seguridad, UX y negocio; concluye que la analítica depende de datos íntegros |
| Transferencia | adaptar de forma independiente destrezas y metodologías a situaciones nuevas o complejas | [Planificación, secciones 3, 6, 10 y 11](Planificacion_Unidad1.md): dos compras simultáneas, transacciones, reglas, restricciones y pruebas |
| Comunicación integrada | seleccionar lenguaje y representaciones visuales que refuercen propósito y significado | tablas numeradas, [diagramas](../diagramas/Diagramas_SmartCommerce.md), README y [guion de video](Guion_Video.md) |
